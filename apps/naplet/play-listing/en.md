# Naplet — baby sleep & feeding tracker

Naps, night sleep, feeds and diapers — logged at 3am with one thumb.

WHY NAPLET IS DIFFERENT
• 3am night mode — giant one-thumb buttons, dim colors, follows your system dark theme. Built for exhausted parents, not demo videos
• Sleep↔feeding insights — simple on-device cards that connect the dots ("early bedtime, few wake-ups — repeat that")
• Family sync — one short code on every caregiver's phone, everyone sees the same timeline. No accounts
• Bilingual from day one — English + Arabic with full RTL, because parenting doesn't happen in one language

FEATURES
• One-tap sleep start/stop timer
• Breast (left/right/both), bottle (ml/oz) and solid feeding log
• Diaper log (wet/dirty/mixed)
• Daily timeline, totals, and streaks
• Long-press any entry to delete
• Works fully offline; syncs when the family code is set

Optional Naplet Pro (weekly plan, 7-day free trial): family sync, sleep insights, unlimited history, early access to new features.

Less tapping. More sleeping. For all of you.
